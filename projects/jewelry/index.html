Wire work and wearable pieces

Small objects need stronger presentation, not smaller ideas.

I mixed the cleaner jewelry documentation already on the site with selected export images so this lane now reads like a body of work instead of a blank category. The page balances two modes: sculptural wire trees and pieces meant to be worn close to the body.

That combination helps the craft read more honestly. Some work asks for a pedestal, some asks for a hand, and both matter.

Wearable pieces.
